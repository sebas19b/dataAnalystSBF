# 📊 Dashboard de Clientes y Ventas — Power BI

##  Descripción del proyecto

Este proyecto consiste en el desarrollo de un dashboard en **Power BI** orientado al análisis de ventas y comportamiento de clientes.

El objetivo principal es transformar los datos disponibles en información útil para identificar patrones comerciales, analizar el comportamiento de los clientes y detectar oportunidades que puedan apoyar la toma de decisiones.

---

##  Objetivo

Analizar diferentes indicadores comerciales para responder preguntas como:

* ¿Cuál es el ticket promedio?
* ¿Cómo se distribuyen las ventas por región?
* ¿Cuál es el promedio de venta por cliente?
* ¿Cuántos clientes pueden considerarse activos?
* ¿Cuántos clientes llevan más de dos años sin realizar una compra?
* ¿Qué oportunidades comerciales pueden identificarse a partir de estos resultados?

---

## 📊 Indicadores analizados

###  Ticket promedio

Permite conocer el valor promedio de cada compra realizada.

###  Ventas por región

Permite identificar cómo se distribuyen las ventas geográficamente y detectar diferencias entre regiones.

###  Promedio de venta por cliente

Permite analizar el valor promedio generado por cada cliente.

###  Clientes activos

Para este proyecto se definió como cliente activo aquel que realizó **al menos una compra durante los últimos dos años**, tomando como referencia la fecha actual.

###  Clientes inactivos

Se considera cliente inactivo aquel cuya **última compra ocurrió hace más de dos años** respecto a la fecha actual.

Esta definición permite diferenciar a los clientes que mantienen actividad reciente de aquellos que podrían representar una oportunidad de reactivación.

---

## 🔎 Enfoque de análisis

El proyecto sigue una estructura orientada al análisis de negocio:

**Datos → Indicadores → Hallazgos → Interpretación → Decisión**

La intención no es únicamente presentar gráficos, sino utilizar los indicadores para identificar situaciones que puedan requerir una acción empresarial.

---

## 💡 Principales oportunidades identificables

A partir del análisis se pueden identificar oportunidades como:

* Diseñar estrategias de reactivación para clientes inactivos.
* Priorizar clientes con mayor valor histórico.
* Analizar regiones con menor nivel de ventas.
* Revisar frecuencia de compra y comportamiento de los clientes.
* Utilizar los indicadores como apoyo para definir futuras estrategias comerciales.

## 🎯 Conclusión

El dashboard permite convertir información de ventas y clientes en indicadores que facilitan la interpretación del comportamiento comercial.

Uno de los principales enfoques del proyecto es la identificación de **clientes inactivos**, ya que este segmento puede representar una oportunidad para desarrollar estrategias de reactivación.

De esta manera, el proyecto demuestra un enfoque que va más allá de la visualización:

> **Un buen análisis de datos no termina en un gráfico; termina cuando el dato ayuda a responder una pregunta de negocio.**
